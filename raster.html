Базовые растровые алгоритмы

Алгоритмы только заполняют виртуальный растр (массив яркостей). Сетка и пиксели рисуются отдельно, уже по данным массива.

Параметры

Клик по полю задаёт точки: первый клик — начало (или центр), второй — конец.

Привязка к сетке. Целочисленная координата (x, y) — центр клетки растра. Ось X вправо, ось Y вверх, начало (0, 0) в центре поля. Линии сетки проходят между клетками, на полуцелых значениях.

Нажмите «Построить», чтобы увидеть пошаговые вычисления.

Стресс-тест (Benchmark)

Случайные отрезки (все 8 октантов) и окружности разного радиуса рисуются в чистый виртуальный растр 1024×1024, без UI. Время измеряется через performance.now().

Структура и пояснения

RasterEngine — статические чистые алгоритмы (stepLine, DDA, Bresenham, Wu, BresenhamCircle), которые пишут только через интерфейс IRasterTarget.setPixel(x, y, intensity). VirtualGrid — двумерная матрица яркостей (Float32Array). GridPainter — UI-компонент, который рисует увеличенные квадраты по данным VirtualGrid.

Брезенхем (линия и окружность) обобщён на все 8 октантов: линия — через знаковые шаги sx, sy и накопление ошибки без деления; окружность — через симметрию в 8 точек. Сглаживание Ву реализовано: интенсивности двух соседних пикселей видны в таблице шагов. Алгоритм Кастла–Питвея в эту версию не входит.
